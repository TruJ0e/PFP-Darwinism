PFP Darwinism

Pass, Fail, Possible — survival of the fittest, for reasoning. Small models, organized, auditable.

Multiple reasoning agents start at once. They split at uncertainty, mutate blindly into unexplored hypotheses, merge when compatible, and die when a falsifier breaks their claims. Every event is written to a hash-chained journal, so the whole run is a tamper-evident proof trail. The point: a small model (30B), organized this way, can reach answers a solo small model never produces — in minutes, for cents — with a trail you can audit.

Watch a run

Education run (5 minutes) — A student with dyslexia, level 1 autism, and ADHD: group reading, disruptive stimming, no sense of when work starts and ends, a 504, and a refusal to do different work from the class. 12 branches, 66 calls, $0.03, done in 148 seconds. Best answer at cutoff: a discreet wearable vibrational cue the student activates to mark work segments — turning regulation into a tool instead of a disruption.

SSH race (60 seconds) — SSH works laptop→desktop but not desktop→laptop. 12 branches, 64 calls, $0.02, halted by the race budget. The falsifier attacked untested branches before any merge — test before merge, enforced in code.

Both replays render from the runs' hash-chained event journals. No winner's-box survivor has been verified yet; the replays show best-verified answers at cutoff, labeled as such.

How it works

  • Briefs, not photocopies. Each starter gets a model-generated exploration brief covering a different region of the hypothesis space, generated against the other briefs. Every descendant gets a brief that diverges from its parent's — inherit the map, never the route.
  • Falsification first. A branch cannot be merged away until it has faced at least one falsifier attack. Selection before recombination.
  • Race mode. A time/call budget with an anytime winner: at the deadline you get the best-verified branch alive, with its verification depth recorded.
  • Proof trail. Spawn, split, merge, attack, fail — every event hash-chained and replayable.
